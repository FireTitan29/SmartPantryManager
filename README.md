# Smart Pantry Manager

## Description

The Smart Pantry Manager allows users to add ingredients with quantities to their household pantry and then matches them to recipes that they would be able to make with the ingredients in their pantry. The application also includes alerts for expiry dates and allows users to customise their preferred measurement unit.

## Database

SQLite was chosen as the database because it means that the application is easy to install and set up. As this project requires lecturers to install and mark a working application, SQLite makes this process easier. Also, because the application is local only, it makes sense to use SQLite because no cloud connections are needed, so the app can run offline.

## Setup and Running

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Android Studio to sync the Gradle project.
4. Start an Android emulator or connect an Android device.
5. Run the application from Android Studio.
6. The SQLite database and recipe data will be created automatically when the application is first run.
